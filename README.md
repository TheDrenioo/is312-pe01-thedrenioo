## Project Description

This project is the beginning of a personal website developed using HTML and CSS.

The website includes a header displaying my name, a biography section, an image, and contact information.

## Project Files

- `index.html` - Contains the HTML structure and content of the website.
- `style.css` - Contains the CSS styling for the website.

## Features

- HTML5 document structure
- External CSS stylesheet
- Header with personal name
- Two-column layout
- Biography section
- Image
- Contact information
- Link to City University of Seattle
- Responsive layout

## How to Run

1. Open the project in GitHub Codespaces.
2. Open the terminal.
3. Run the following command:

```bash
python3 -m http.server 8000
```

4. Open the forwarded port 8000 in your browser.
